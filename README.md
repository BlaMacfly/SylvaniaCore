## Introduction

**ArgusCore** is an open-source *MMORPG* server framework written mostly in C++,
targeting **World of Warcraft: Legion** (client build **7.3.5.26972**).

It is a community project maintained by the team behind *The Kingdom of Sylvania*.

## Lineage

ArgusCore stands on the shoulders of the projects it derives from:

```
TrinityCore  ->  AshamaneCore (Legion 7.3.5)  ->  ArgusCore
```

All upstream work remains under the **GPL-2.0** license. ArgusCore keeps the
original copyrights and credits intact and tracks AshamaneCore as `upstream`
so blizzlike fixes can be merged.

## Features

Inherited from AshamaneCore / TrinityCore and being extended:

- Legion scripts & content (Mardum / Demon Hunter start, Class Hall basics, World Quests, Mythic+, dungeons WIP)
- WoD, Pandaria, Cataclysm zones & world bosses
- TimeWalkers (BC / WotLK / Cataclysm / MoP)
- Rated Arenas, mercenary battlegrounds
- Argus Database (ADB) world & hotfixes for 7.3.5

## Requirements

Software requirements are the same as TrinityCore (Legion) for Windows, Linux and macOS.

## Install

Detailed installation guides for the TrinityCore/AshamaneCore lineage apply.
A working local deployment (server + frFR client) is documented in the project notes.

## Reporting issues

Open an issue on the [ArgusCore GitHub repository](https://github.com/BlaMacfly/ArgusCore/issues).

## Submitting fixes

C++ fixes are submitted as pull requests via GitHub. For SQL-only fixes, open a ticket.
